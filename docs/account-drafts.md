# 계정별 사고보고 초안 (r168)

작성 중인 사고보고, 재발방지계획, 재발방지조치는 본인 계정의 서버 초안에 저장된다. 다른 기기에서 같은 계정으로 로그인하면 작성 중인 자료에서 이어 쓸 수 있다. 현장 첨부자료의 사진 촬영 버튼은 모바일 후면 카메라 입력을 요청하며, 사진 또는 파일 선택 버튼도 유지된다.

- 실제 접수 전에는 사고 집계, 검토 알림, 결재 이력에 포함하지 않는다.
- 서버 저장 완료 표시를 확인한 뒤 기기를 바꾼다. 통신 실패 시 입력 내용과 마지막 서버 기준본을 기기의 복구용 outbox에 보관한다.
- 원본 기준, 이 기기 내용, 서버 최신 내용의 세 값을 비교한다. 겹치지 않는 수정은 병합하고 같은 항목이나 첨부 목록이 충돌하면 항목별 선택을 요구한다.
- 저장 및 삭제는 revision 비교로 보호한다. 제출은 초안 revision 검사와 정식 사고 기록 저장을 한 트랜잭션에서 수행한다. 실패 시 초안을 유지한다. 제출/삭제된 초안은 내용이 비워진 상태 표식을 남겨 오래된 기기의 재저장을 차단한다.
- 기존 브라우저 초안은 해당 기기에서 로그인한 뒤 서버 저장이 확인되면 정리한다. 이전 입력내용이나 권한/버전 문제로 전환하지 못한 내용은 복구본으로 보존한다.
- 서버 인증으로 확인한 본인 계정만 초안을 읽고 변경할 수 있다. private 스키마, RLS 및 공개 역할 권한 회수로 Data API 접근을 차단한다. 첨부에는 기존 소유자/정식 사고 접근 검증을 적용한다.

검증: account-drafts-api.cjs는 실제 Edge 핸들러와 격리 PostgreSQL에서 권한, 충돌, 재시도, 제출 원자성, 알림 미발생을 검사한다. account-drafts-dom.cjs는 별도 DOM 환경의 기기 간 복원, 사진 병합, 충돌 선택, 오프라인 복구, 이전 초안 전환, 실제 비동기 보고 제출 핸들러를 검사한다. form-drafts-browser.cjs는 Chromium/WebKit용 별도 브라우저 CI 검사이며 로컬 실행 결과와 구분한다.
