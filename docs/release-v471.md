# 4.7.1 — A4 한 장 엑셀 사고보고서

사고 상세 화면의 PDF 보고서 버튼을 엑셀 사고보고서 다운로드로 변경한다. 새 창이나 인쇄 팝업 없이 브라우저에서 XLSX를 생성하며, 원본 열람 권한이 있는 사용자는 종결 전에도 출력할 수 있다.

- 사고 개요, 사고 경위·피해·즉시 조치, 원인·재발 방지, 보고·검토 순서로 구성한다.
- A4 세로, 인쇄영역 A1:L45, 한 페이지 맞춤, 상하좌우 12mm 여백, 동일 열 너비와 기본 행 높이를 적용한다.
- 긴 내용은 본문에 전문 번호를 표시하고 ‘내용 전문’ 시트에 이어서 보존한다. 기본 인쇄 대상은 첫 시트 한 장이다.
- 한국시간, 시간 미확인, 확인된 비용 0원, 미확인 비용, 조사 중 원인과 승인 전 상태를 구분한다.
- 파일 생성은 현재 조회한 자료를 사용하며 서버 자료나 승인 상태를 변경하지 않는다. 기존 최종 사고보고서와 첨부자료 출력 기능은 유지한다.
- 새 스크립트를 운영·데모 진입점과 PWA 캐시에 추가한다.

검증: Node 회귀검사, 실제 브라우저 버튼을 통한 XLSX 다운로드, Microsoft Excel 읽기 전용 열기 및 A4 한 페이지 출력, 인쇄 결과 육안 확인. 실제 운영 사고자료를 생성하거나 수정하지 않았다.
