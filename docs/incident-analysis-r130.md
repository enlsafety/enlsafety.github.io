# r130 사고 종합분석과 처리 상태, 서류 메뉴 전환

## 변경

- 사고보고 내부 종합분석 탭: safety, manager, executive (기존 final 별칭 포함)만 진입한다. 기존 서버 동기화의 확인된 사고 스냅샷을 복제해 읽으며 추가 분석 API나 AI 호출은 없다.
- 최초사고보고의 최신 저장 내용을 사고 ID별로 집계한다. 과거사고 입력은 포함하고 임시저장, 무효, 삭제 기록은 제외한다. 발생일은 한국시간으로 해석한다.
- 전체 기간 기본값, 연도 및 사업장 선택, 월별 추이, 사고유형, 사업장, 업무별 분포, 인명/대물 사고와 입력 비용을 표시한다. 미확인 비용은 합계에서 제외하고 건수를 표시한다. 사업장 빈도는 사고율로 표시하지 않는다.
- 처리중 표시는 첨부파일 처리와 사용자 사고 저장에만 적용한다. 브라우저 안의 단일 회색 레이어이며 서버 요청, 반복 타이머, 애니메이션은 없다. 화면 입력은 즉시 잠그고 글씨는 180ms 이후 표시한다. 중첩 작업과 실패 시에도 원래 입력 상태를 복구한다.
- 조직도와 위험성평가 목록 API는 기존 서버에서 모듈 접근과 사용자 권한을 검사하므로, 이 두 메뉴의 별도 platform_enter 왕복을 생략한다. 목록 자체의 서버 검사는 그대로 유지한다. 진행 중인 동일 목록 요청은 공유하고 쓰기 후에는 목록 요청을 새로 한다. 장기 캐시를 추가하지 않았다.
- 위험성평가 서류 안에서 브라우저 포커스가 돌아올 때 사업장 목록으로 되돌아가지 않는다.
- r130 진입 페이지, 서비스워커와 변경된 정적 자산 캐시 키를 갱신했다.
